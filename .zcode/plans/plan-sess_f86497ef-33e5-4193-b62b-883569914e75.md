# 修复数据报表页的类型混乱和统计错误

## 根因分析

1. **复合类型统计错误**：
   - 数据库中某些电影的Genre字段存储复合类型（如"剧情/犯罪"）
   - 后端SQL使用LIKE模糊匹配（`m.Genre LIKE '%剧情%' OR m.Genre LIKE '%犯罪%'`）
   - 导致一个电影被多次统计，总和大于实际数量

2. **图表数据索引错位**：
   - 前端使用硬编码的`movieGenres`数组（9个元素）
   - 但后端返回的`tableData`可能只有部分类型有数据
   - 图表的xAxis和series数据索引不匹配

3. **字段命名混乱**：
   - 后端SQL使用驼峰命名，但前端映射逻辑过于复杂

## 修复方案

### 1. 后端修复：ReportController.java

**位置**：`Movie_Rating_Backend/src/main/java/movie_rating_backend/controller/ReportController.java`

**修改内容**：
- 将所有SQL查询中的LIKE模糊匹配改为IN精确匹配
- 移除第37-39行和第61-63行的动态LIKE条件
- 修改为固定的IN条件：`Genre IN ('剧情', '喜剧', '动作', '爱情', '科幻', '动画', '悬疑', '犯罪', '奇幻')`

**代码改动**：
```java
// 修改第37-39行和第61-63行的LIKE条件为IN条件
String likeConditions = MOVIE_GENRES.stream()
    .map(genre -> "'" + genre + "'")
    .collect(java.util.stream.Collectors.joining(", "));
// 使用IN而非LIKE

String likeConditionsNoAlias = MOVIE_GENRES.stream()
    .map(genre -> "'" + genre + "'")
    .collect(java.util.stream.Collectors.joining(", "));
// 使用IN而非LIKE
```

### 2. 前端修复：Report.vue

**位置**：`movie-rating-frontend/src/views/Report.vue`

**修改内容**：

#### 修改1：图表数据动态提取（第138行）
```javascript
// 改为从tableData动态提取genres
const genres = tableData.value.map(d => d.Genre)
```

#### 修改2：简化数据映射逻辑（第212-219行）
```javascript
// 简化为单一映射，移除复杂的多重备选
tableData.value = list.map(d => ({
  Genre: d.Genre,  // 后端返回驼峰命名，直接使用
  Count: Number(d.Count) || 0,
  AvgRating: Number(d.AvgRating) || 0,
  MaxRating: Number(d.MaxRating) || 0,
  MinRating: Number(d.MinRating) || 0,
  TotalComments: Number(d.TotalComments) || 0
})).filter(item => item.Count > 0)
```
