## 清理方案：电影评分系统前后端冗余/无用代码

**范围**：高+中置信度（已逐项 grep + 读源码核验无引用）。LOW 项（注释掉的零碎行、HELP.md、favicon 修正）本次不动。重复函数 `getMovieList`/`searchMovies` 合并为 `searchMovies`。

### A. 后端（Spring Boot）

**A1. 删除 4 个完全无引用的 DTO 文件**（控制器均直接用实体类 `@RequestBody`，且无 `@Valid`，校验注解形同虚设）
- `DTO/CommentDTO.java`、`DTO/RatingDTO.java`、`DTO/MovieQueryDTO.java`、`DTO/RegisterDTO.java` 整文件删除
- 保留 `LoginDTO`（AuthController 在用）

**A2. 删除 movie 死链（service→mapper→XML 全无调用方；MovieController.search 用自己的 QueryWrapper+selectPage）**
- `service/MovieService.java`：删 `search(...)`(11) 与 `getAllMoviesWithDetails()`(12)；连带删无用的 `import BigDecimal`(6)、`import List`(7)
- `service/impl/MovieServiceImpl.java`：删 `getAllMoviesWithDetails()`(24-28) 与 `search(...)`(29-32)；连带删 `import BigDecimal`(10)、`import List`(11)
- `mapper/MovieMapper.java`：删 `selectAllWithDetails()`(17) 与 `searchMovies(...)`(19-22) + 其上注释(19)；连带删 `import BigDecimal`(9)、`import List`(10)
- `resources/mapper/MovieMapper.xml`：删 `<select id="selectAllWithDetails">`(50-61) 与 `<select id="searchMovies">` 及其上注释(63-78)；保留 `MovieDetailMap` resultMap 与 `selectOneById`（MovieController:73 在用）

**A3. 删除 Director 死方法 `selectPage`（控制器用继承的 `page()`，不用它）**
- `service/DirectorService.java`：删 `selectPage(...)`(12)；连带删 `import QueryWrapper`(2)、`import IPage`(3)、`import Page`(4)（保留 List/Movie/IService/Director）
- `service/impl/DirectorServiceImpl.java`：删 `selectPage(...)`(15-18)；连带删 `import QueryWrapper`(7)、`import IPage`(8)、`import Page`(9)
- 保留 `searchMovies`（DirectorController 在用）

**A4. 删除孤儿 mapper 接口方法 / 语句 / resultMap（均无对应调用方）**
- `mapper/CommentMapper.java`：删 `findCommentsByUserId(...)`(14)（无 XML、已损坏）；**保留 `findCommentsByMovieTitle`(13)**（存储过程调用示例，见下方说明）
- `resources/mapper/CommentMapper.xml`：删 `CommentMap` resultMap(6-12) 与 `getCommentsByMovieId` select(20-23)（服务层用 MyBatis-Plus `list(QueryWrapper)` 实现，此 XML 语句无对应接口方法，孤儿）；保留 `findCommentsByMovieTitle` SP(14-18) 与 `getUserComments`(25-32)
- `mapper/UserMapper.java`：删 `findByUsername(...)`(10)；连带删 `import Param`(6)（接口保留为空的 `BaseMapper<User>` 声明，UserServiceImpl 仍引用）
- `resources/mapper/UserMapper.xml`：删 `UserMap` resultMap(6-12) 与 `findByUsername` select(14-16)，留空 mapper 壳（UserServiceImpl 用 LambdaQueryWrapper）
- `resources/mapper/RatingMapper.xml`：删 `MovieRatingMap` resultMap(4-14)（代理漏报，我已查实无 `resultMap="MovieRatingMap"` 引用，各 select 用 resultType+别名自动映射）、`getRatingCount`(48-50)、`getRatingCountByUserId`(51-53)；保留 `insertOrUpdate`/`updateRating`/`getUserMovieRating`/`getUserRatings`/`getAverageRating`（均在用）
- `resources/mapper/ActorMapper.xml`：删 `ActorMap` resultMap(6-13)；保留 `searchMovies` SP（ActorController 在用）
- `resources/mapper/DirectorMapper.xml`：删 `DirectorMap` resultMap(6-12)；保留 `searchMovies`（在用）

**A5. 删除未用工具方法 / 调试代码 / 死配置**
- `utils/Result.java`：删 `success(String msg, T data)` 重载(18-20)（2 参调用零次）
- `utils/JwtUtil.java`：删 `System.out.println("token: " + token);`(34)（每次鉴权都打印原始 token）
- `resources/application.yml`：删 `jwt:` 配置块(17-19)（JwtUtil 用硬编码常量，未读此配置；属死配置。注：更彻底的做法是把 JwtUtil 改为读取此配置，但那是重构非删废码，本次按"删无用"处理）
- `config/GlobalExceptionHandler.java`：删 `handleValidException`(16-19) 与 `import MethodArgumentNotValidException`(4)（全项目无 `@Valid`，该异常永不触发）；保留 `handleException`

**A6. WebMvcConfig 冗余排除路径**
- `config/WebMvcConfig.java`：删(21-23) 的具体路径（`/api/movie/list` 等 8 条）——它们是(24-26) 宽通配 `/api/movie/**` `/api/actor/**` `/api/director/**` 的严格子集，删后行为不变
- 注：(24-26) 宽通配同时把 POST/PUT/DELETE 的 movie/actor/director 端点也免了登录——这是既有逻辑（可能的 bug），但删冗余子集不改变它，属行为问题不在本次范围

**A7. 实体类无用 import（中）**
- `entity/MovieComment.java`：删 `IdType`、`TableId`、`BigDecimal`
- `entity/MovieRating.java`：删 `IdType`、`TableId`、`BigDecimal`
- `entity/Comment.java`：删 `IdType`（TableId 保留在用）
- `entity/Rating.java`：删 `IdType`、`BigDecimal`
- （实现时会逐个 Read 确认字段后再删）
