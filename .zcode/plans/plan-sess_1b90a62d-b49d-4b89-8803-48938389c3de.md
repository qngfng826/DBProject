# 电影详情页修复计划

## 问题诊断

### 问题1：电影详情页不显示所有评论
**根本原因**：CommentServiceImpl.getCommentsByMovieId()方法使用了小写字段名`movieid`，但数据库表comment1707使用的是大写字段名`MovieID`

**影响范围**：
- `Movie_Rating_Backend/src/main/java/movie_rating_backend/service/impl/CommentServiceImpl.java` (第20行)

### 问题2：电影详情页不显示登录用户的评分
**根本原因**：MovieMapper.xml的selectOneById查询返回了UserRating字段，但Movie实体类中没有对应的字段来接收

**影响范围**：
- `Movie_Rating_Backend/src/main/resources/mapper/MovieMapper.xml` (需要添加字段映射)
- `Movie_Rating_Backend/src/main/java/movie_rating_backend/entity/Movie.java` (需要添加userRating字段)

## 修复方案

### 修复1：修正评论查询的字段名
**文件**：`Movie_Rating_Backend/src/main/java/movie_rating_backend/service/impl/CommentServiceImpl.java`

**修改内容**（第20行）：
```java
// 修改前
return list(new QueryWrapper<Comment>().eq("movieid", movieId));

// 修改后
return list(new QueryWrapper<Comment>().eq("MovieID", movieId));
```

### 修复2：在Movie实体类中添加userRating字段
**文件**：`Movie_Rating_Backend/src/main/java/movie_rating_backend/entity/Movie.java`

**添加内容**（在第32行后，List<Actor> actors之后）：
```java
@TableField(exist = false)
private BigDecimal userRating;
```

### 修复3：在MovieMapper.xml中添加UserRating映射
**文件**：`Movie_Rating_Backend/src/main/resources/mapper/MovieMapper.xml`

**修改内容**：
1. 在resultMap `MovieDetailMap` 中添加UserRating映射（在第15行后）：
```xml
<result column="UserRating" property="userRating"/>
```

2. selectOneById查询已经正确（第51行），无需修改SQL，只需确保映射正确
