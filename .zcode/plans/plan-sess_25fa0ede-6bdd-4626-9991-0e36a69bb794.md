## 修复：新增电影弹窗的演员信息残留

### 根因

MovieManage.vue 的 openDialog 用 `Object.assign(form, defaultForm)` 重置表单，浅拷贝导致 `form.actors` 与 `defaultForm.actors` 共享同一数组引用；演员行通过 push/splice/直接改属性原地修改，把 defaultForm 一并污染，下次打开新增弹窗时残留信息被拷回。

（标题等字段是字符串值拷贝不受影响；导演 directorIds 因 el-select 替换新数组也未受影响。）

### 修改

MovieManage.vue `openDialog` 新增分支改为：
```javascript
Object.assign(form, defaultForm, { directorIds: [], actors: [], directors: [] })
```
数组字段赋全新空数组，切断引用共享。编辑分支已用 .map() 生成新数组，无需改动。

### 验证

前端刷新后手动验证：新增 → 填演员 → 取消 → 再新增（应为空）；保存路径同样验证。
