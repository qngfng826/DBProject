## 修复 CORS 跨域错误

**问题**：Spring Security 配置中缺少 CORS 支持，导致浏览器发送的 OPTIONS 预检请求被拦截，无法获取响应头。

**修复步骤**：

1. **修改 `SecurityConfig.java`**
   - 在 `filterChain` 方法中添加 `.cors().and()` 配置
   - 这将启用 Spring Security 内置的 CORS 支持
   - Spring Security 会使用 `WebMvcConfig` 中已经配置好的 CORS 设置

2. **验证修复**
   - 修改后重新部署后端服务
   - 测试从 `https://movie-rating.pages.dev` 访问 `https://dbproject-xy1p.onrender.com/api/user/search` 接口
   - 确认浏览器不再报 CORS 错误

**修改内容**：

在 `SecurityConfig.java` 的 `filterChain` 方法中，在 `.authorizeHttpRequests(authz -> ...)` 之前添加：
```java
.and()
.cors()
```

**修改后的代码结构**：
```java
http
    .csrf().disable()
    .sessionManagement().sessionCreationPolicy(SessionCreationPolicy.STATELESS)
    .and()
    .cors()  // 添加这一行
    .and()
    .exceptionHandling(...)
    .and()
    .authorizeHttpRequests(authz -> ...)
```
